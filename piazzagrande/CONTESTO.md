# piazza grande 2026|2027 — contesto di lavoro

Guida educatori giovani, Azione Cattolica Italiana – Settore giovani, Ave 2026.
Struttura del volume (dall'indice, p. 43 del PDF): introduzione, istruzioni per l'uso,
modulo iniziale *Tra la gente*, modulo centrale *In piazza* (sottomoduli: Elasticità,
Dono, Manifestazione, Fermento, Ecclesialità), *Rilettura del modulo centrale*,
modulo finale *Larghe vedute*, traccia campo scuola, appunti, indice.

## Convenzioni Markdown
- Titoli dei moduli (Tra la gente, In piazza, Larghe vedute…) = H1
- Titoli sezione / sottomodulo (es. "CHI EDUCA… È UN DISCEPOLO MISSIONARIO", "Elasticità") = H2
- Rubriche ricorrenti dentro un sottomodulo (Obiettivo generale, Contenuto formativo,
  Laboratori, Per riflettere…, All'ombra, Scegliere, Interpretare, Ricomincio…) = H3
- Citazioni dal Progetto formativo (box colorati) = > blockquote + (PF, p. N)
- Post-it gialli con domande = > [!question]
- Box tondi arancioni ("Cosa vuol dire…?") = > [!tip]
- Riquadri "Su materialiguide.azionecattolica.it / Scheda …" e altri box informativi (QR, Avvento-Natale, Quaresima-Pasqua) = > [!note]
- Attività dei sottomoduli = #### Attività: Titolo (eventuale "(con videotestimonianza)" incluso)
- Brano evangelico della rubrica Interpretare = titolo in **grassetto** + riferimento biblico, testo in *corsivo*
- Nomi degli autori in maiuscoletto nelle bibliografie = **grassetto**
- Pagine di chiusura del volume (Adoro il lunedì, Dicci la tua!, Indice) = H1
- Note a piè di pagina: nel file finale sono rinumerate per pagina ([^p35-1]) da assembla.py
- Firme a fine sezione = *— Nome Cognome*, ruolo
- Note a piè di pagina = [^n], raccolte a fine capitolo
- Numeri di pagina del libro = <!-- p. N --> come commento HTML, all'inizio di ogni pagina
- Corsivi dell'originale = *asterischi*; maiuscoletto = **grassetto**
- Pagine di sola immagine/pubblicità = una riga <!-- p. N: immagine / pubblicità … -->
